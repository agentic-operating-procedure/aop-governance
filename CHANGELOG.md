# Changelog

All notable changes to this repository are documented here. Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Versioning is semantic: the major version changes when an authority boundary moves, the minor version when normative content is added, and the patch version for corrections that do not change meaning.

## [Unreleased]

## [0.2.0] - 2026-11-06

### Added

- The reviewer independence and claims discipline layer (GI-1 to GI-10): implementer-or-domain review outside the authoring path for normative CRs, conflict declarations, two-approval quorum with recorded dissent that travels with dependent claims, an appeal path through findings, mandatory claim citation, correction and withdrawal, stewardship succession.
- The change request register (CR-001 to CR-033) with landing states and named remainders.
- The metamodel reconciliation closures (points 1, 3, 4; 6 settled earlier): the hierarchy-and-metamodel map with the classification rule, and the dispositions for the harness relationship and compiled-versus-authored provenance.
- CR-038: Zero-TAF recognised as the trust framework whose runtime realisation AOP profiles; the mapping direction is one-way and ADR-0004 stands.
- The programme plan addendum: the hardening waves H1 to H5 and the estate's current state.

### Changed

- The change model (v0.1.1): the CR section records the second-approval requirement for normative CRs.

## [0.1.0] - 2026-11-03

### Programme foundation

- Seeded the repository with the change model: the ADR, CR, and finding artefact classes, the lifecycle model, the release policy, and the contributor rules.
- Published the programme plan, the repository map of fourteen repositories across eleven tiers, the org-wide cascade checklist, and the concept model under `plans/`.
- Published the foundational architectural decision record set, ADR-0001 through ADR-0010.
- Recorded CR-001, the bootstrap landing of the Wave 1 governance surface.
